# Agent-readable docs: /llms.txt, /llms-full.txt, and regenerated openapi.json

## Goal
Serve the complete agent-facing API reference as markdown at a linkable URL, and
regenerate `api/openapi.json` from the same source.

## Why
The operator wants one link to hand an agent that fully explains what this box can
do. Today there is no markdown doc route anywhere, `GET /api/info` is a
hand-maintained partial blob, and `api/openapi.json` is stale (Feb 19) and missing
whole route families. Generating all three from `api/api-spec.js` is what stops
them drifting apart again.

## Depends on
The API spec module task, and the transcriptions task (so the surface is complete
before generating).

## Files to touch
- `api/server.js` (route registration only)
- `api/openapi.json` (regenerated output, committed)
- `api/api-spec.js` (only to fill gaps discovered while generating)

## Reference files
- `api/api-spec.js` — the `ENDPOINTS` array and `scripts/gen-openapi.mjs`.
- `api/server.js:6395-6402` existing `GET /api/openapi.json`; `:6405-6434`
  `GET /api/info` ("Simple API info endpoint for agents"); `:9512` SPA catch-all.
- Design doc §5.6.

## What to build
1. `GET /llms.txt` — short index: product name, base URL
   (`http://<host>:5250/v1`), one-paragraph capability summary, the endpoint list,
   and a pointer to `/llms-full.txt`. Follow the llms.txt convention.
2. `GET /llms-full.txt` — the complete agent-readable markdown: every endpoint with
   params and schemas, the **full multimodal content-part contract** (standard
   `text`/`image_url`/`input_audio` plus the `video_url`/`audio_url` extensions),
   worked examples in curl/python/javascript **including a YouTube link example**,
   the documented limits (window length, frame cap, 200 MB body cap, 720p YouTube
   ceiling), and the digest/`metadata.llama_manager_media` reporting contract.
3. Alias both at `/api/llms.txt` and `/api/llms-full.txt`.
4. Serve `text/markdown; charset=utf-8`. Generate from `ENDPOINTS` at request time
   or at startup — **never hand-write the markdown**.
5. Regenerate and commit `api/openapi.json` via `scripts/gen-openapi.mjs`.
6. Update `GET /api/info` to advertise the new doc URLs.

**All routes must register before `api/server.js:9512`**, or the SPA catch-all
swallows them.

## Public surface changes
`GET /llms.txt`, `GET /llms-full.txt` (+ `/api/` aliases); refreshed
`api/openapi.json`; `/api/info` gains doc links.

## Acceptance criteria
- [ ] `curl -s http://localhost:5250/llms.txt` returns markdown, not the SPA HTML.
- [ ] `/llms-full.txt` documents every route in `ENDPOINTS`, and a diff against the
      live route list shows no missing route.
- [ ] Regenerated `openapi.json` includes `/api/media/*` and the audio routes.
- [ ] `./scripts/dev-build.sh check` and `container` pass.
